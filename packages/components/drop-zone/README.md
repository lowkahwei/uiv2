# @sytechui/drop-zone

HeroUI styled drag-and-drop target built on top of React Aria's `useDrop` and `useClipboard`.

The component supports pointer drag and drop, keyboard focus, and clipboard paste handling with the same state-driven slot styling used across the rest of HeroUI.

## Installation

```sh
yarn add @sytechui/drop-zone
# or
npm i @sytechui/drop-zone
```
