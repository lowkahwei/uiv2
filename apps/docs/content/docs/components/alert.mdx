## Usage

<CodeDemo title="Usage" files={alertContent.usage} />

### Anatomy

Access every part through the `Alert` compound component.

```tsx
<Alert>
  <Alert.Indicator />
  <Alert.Content>
    <Alert.Title />
    <Alert.Description />
  </Alert.Content>
</Alert>
```

Use `default`, `accent`, `success`, `warning`, or `danger` to convey the message status.

## Data Slots

- `alert-root`
- `alert-indicator`
- `alert-default-icon`
- `alert-content`
- `alert-title`
- `alert-description`

## Accessibility

The root uses `role="alert"` so important dynamic messages are announced by assistive technology.
Interactive controls remain explicit children, so their labels and behavior stay under application
control.

### Alert.Indicator Props

`className` and `children`. Its children replace the default status icon.

### Alert.Content Props

`className` and `children`.

### Alert.Title Props

`className` and `children`. Renders a `p` by default.

### Alert.Description Props

`className` and `children`. Renders a `span` by default.

All parts also accept native props and the polymorphic `as` prop.
